# Farm Parity PC

Ein gemütliches Farmspiel im Stil von Harvest Moon.

**Download:** Unter [Releases](https://github.com/Rucksack204/farm-parity/releases/latest) die Datei `FarmParity_Windows_vX.zip` herunterladen, entpacken und `FarmParity.exe` starten.

Windows SmartScreen: „Weitere Informationen“ > „Trotzdem ausführen“.

Das Spiel sucht selbst nach Updates und fragt vorher.
